# Activity 2: Logic Building Challenge Students solve progressively complex logical problems using flowcharts and pseudocode before implementing them in code.
# Solution
Objective: To develop students’ logical thinking and problem-solving skills by solving problems using flowcharts, pseudocode, and programming code.

## 1. Problem-Solving Process

Step 1: Understand the Problem

Step 2: Write Pseudocode

Step 3: Draw a Flowchart

Step 4: Implement the Code

Step 5: Test and Debug

## 2. Progressive Challenges

### Level 1 — Beginner

Problem: Check whether a number is even or odd.

Pseudocode

```
START
INPUT number
IF number MOD 2 = 0
    PRINT "Even"
ELSE
    PRINT "Odd"
END IF
STOP
```

Sample: Input: `7` → Output: `Odd`

### Level 2 — Intermediate

Problem: Find the largest of three numbers.

Pseudocode

```
START
INPUT A, B, C
IF A >= B AND A >= C
    PRINT A
ELSE IF B >= C
    PRINT B
ELSE
    PRINT C
END IF
STOP
```

Sample: Input: `12, 25, 18` → Output: `25`

### Level 3 — Advanced

Problem: Calculate the factorial of a positive integer.

Pseudocode

```
START
INPUT N
FACTORIAL = 1
FOR I = 1 TO N
    FACTORIAL = FACTORIAL * I
END FOR
PRINT FACTORIAL
STOP
```

Sample: Input: `5` → Output: `120`

## 5. Expected Learning Outcomes

- Develop logical and analytical thinking.
- Convert real-world problems into algorithms.
- Understand flowcharts and pseudocode.
- Implement algorithms using programming languages.
- Identify and correct errors through testing.

Suggested duration: 30–45 minutes in small groups of 2–4 students.
