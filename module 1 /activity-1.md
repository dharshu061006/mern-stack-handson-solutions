#Activity 1: How the Internet Works
Students simulate the interaction between a browser, server, and database to understand how requests are processed and responses are returned. 
#Solution
Objective: To understand how a browser, web server, and database communicate to process requests and return responses.

## 1. Basic Architecture

1\. Browser (Client)

User requests a webpage

HTTP Request

2\. Web Server

Processes the request

Database Query

3\. Database

Stores and retrieves data

The response returns from the database to the server, then to the browser.

## 2. Steps Involved

1. User action: The user enters a website URL or clicks a button in the browser.
2. Request: The browser sends an HTTP/HTTPS request to the web server.
3. Processing: The server processes the request and queries the database if necessary.
4. Database response: The database returns the requested information to the server.
5. Server response: The server sends an HTTP response containing data or webpage content.
6. Display: The browser displays the result to the user.
