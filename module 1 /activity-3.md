## 5. Expected Learning Outcomes

By completing this activity, students will be able to:

- Differentiate frontend, backend, and database components.
- Understand the architecture of everyday applications.
- Trace how user requests and data flow through an application.
- Connect real-world applications to web development concepts.

Suggested duration: 30–40 minutes. Students can work in groups of 3–4 and present their application mapping to the class.
